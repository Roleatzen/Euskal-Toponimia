# Euskal Toponimia Generator

Generador experimental de toponimia vasca, histórica y proto-vasca.

## GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch.

Branch: `main`  
Folder: `/ (root)`

Tras subir cambios, GitHub Pages puede tardar unos minutos. Si aparece la versión anterior, usa `Ctrl + F5`.

## Modos

- **Documental**: selección conservadora.
- **Vasco**: modo generativo principal.
- **Histórico**: generación con transformaciones históricas opcionales.
- **Proto**: generación experimental.

Los cuatro modos tienen patrones disponibles. Los patrones antiguos sin `modes` también reciben compatibilidad automática.

Una forma generada no implica que sea un topónimo históricamente documentado.
